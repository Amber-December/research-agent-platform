# Paper Init

Treat initialization as the stable boundary for every writing, review, and rebuttal workflow.

1. Inventory every supplied source with original name, workspace-relative path, hash or stable ID, file type, extraction warning, and page/paragraph location where available.
2. Classify it as literature, notes, outline, method, result, figure, bibliography, existing draft, reviewer comments, or other.
3. Record the requested deliverable, language, document type, target venue, must-preserve facts, source scope, and author constraints.
4. Freeze a WritingPackage before prose. The package must name admissible source IDs, missing inputs, and whether a later stage may retrieve externally.
5. Preserve source identity; do not silently replace uploads with generated summaries. Keep all generated artifacts inside the current session workspace.
6. Recommend the next workflow from the actual material state: evidence search for a missing corpus, drafting for a sufficient writing package, or diagnosis/rebuttal for an existing manuscript.

The initialized package is a provenance contract, not a claim that the sources are complete or correct.
